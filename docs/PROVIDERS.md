# Providers

Pi maintains the provider registry and authentication integrations. See https://pi.dev/docs/latest/models and use Pi's supported login/API-key flows. Gemini developer API free tiers, OpenRouter free models, Groq developer tiers and local Ollama-compatible endpoints may be options, but quotas, pricing, availability, region eligibility and tool support change. Verify official terms before configuring.

A ChatGPT subscription is not automatically API access. Do not extract browser cookies, automate consumer chat websites as unofficial APIs, evade quotas, or silently switch to paid providers. No live provider credentials were available during initial implementation; none is claimed as tested.
\n## Harness allowlist\n\nBy default, `freeModels` is empty and the wrapper blocks interactive and one-shot model execution. After verifying provider pricing/terms and tool support, add exact `provider/model-id` values to `freeModels`; the wrapper scopes Pi to those IDs. `allowPaidModels: true` is an explicit opt-in that removes the wrapper allowlist. This is not a billing meter: daily/task budget fields are configuration placeholders and do not enforce provider charges.\n
